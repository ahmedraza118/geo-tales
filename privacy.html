Privacy Policy

Geo Tales Studio. Last updated 9 November 2026.

Geo Tales Studio is a private tool used only by the owner of the Geo Tales YouTube channel. It is not offered to the public.

Google and YouTube data

With the channel owner's permission, the tool uses YouTube API Services to upload videos to the owner's channel, set their details, and read the channel's videos, analytics and comments.

How the data is used

The data is used only to publish the owner's videos and to report to the owner how they perform.

Storage and sharing

Access credentials and reports are stored on the owner's own computer. Channel statistics, video titles and scripts, and public viewer comments are sent to Anthropic's Claude service to produce performance analysis for the owner. The data is not sold and is not used for advertising.

Viewers

The tool reads public comments left on the channel's videos. It does not collect any other information about viewers beyond the combined statistics YouTube Analytics provides.

YouTube API Services

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be removed at any time from Google account permissions. Locally stored data can be deleted from the owner's computer.

Contact

Questions can be sent through the Geo Tales YouTube channel.
